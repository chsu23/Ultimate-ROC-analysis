# ROC Analysis Tool (GitHub Pages Edition)

This version can be deployed directly to GitHub Pages. No Python installation or backend server is required.

## Deployment
1. Upload all files in this folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder, then save.

## Interface layout
Markers 1–5 are aligned row by row with their corresponding ROC direction controls, reducing the chance of selecting or reading the wrong marker direction.

## Privacy
All analyses are performed in the browser. Do not commit real patient data or identifiable information to the GitHub repository.
