# ROC Analysis Tool (GitHub Pages Edition)

This version can be deployed directly to GitHub Pages. No Python installation or backend server is required.

## Deployment
1. Upload all files in this folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder, then save.

## Interface layout
Markers 1–5 are aligned row by row with their corresponding ROC direction controls, reducing the chance of selecting or reading the wrong marker direction.

## Privacy
All analyses are performed in the browser. Do not commit real patient data or identifiable information to the GitHub repository.

## Page-view counter
The page includes a visible page-view counter powered by `hits.sh`. The counter key is generated automatically from the deployed hostname and path, so no repository-specific configuration is required.

- It counts **page loads / page views**, not verified unique users.
- It is hidden when the HTML file is opened locally with `file://`.
- Uploaded Excel/CSV data and analysis results are not sent to the counter service.
- Because the counter is provided by a third-party service, its availability depends on that service.

For verified unique-visitor analytics or a global count of completed analyses, connect a dedicated analytics service such as GoatCounter; that requires a site/account and site code.
