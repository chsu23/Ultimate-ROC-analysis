Advanced Performance Comparisons

All comparison tests are disabled by default. Enable only the tests required to compare two or three ROC models. Tests may be run separately or together.

Compares the maximum Youden index across models.
Assumptions: Models must be evaluated in the same cases using the same binary outcome. Every included case must have valid scores for both models, and the dataset must contain both positive and negative cases.
View the complete Youden index comparison procedure
  1. Construct an ROC curve for each model using the original complete-case dataset and calculate the maximum J = Sensitivity + Specificity − 1.
  2. Candidate cutoffs are midpoints between adjacent observed values. If multiple cutoffs yield the same maximum J, their median is used.
  3. Positive and negative cases are resampled separately with replacement while preserving the original class sizes.
  4. All models use the same resampled case indices in each bootstrap iteration, preserving the paired design.
  5. The ROC direction determined from the original data is fixed. In each resample, the maximum J is re-optimized for every model and ΔJ* = J1* − J2* is calculated.
  6. Repeat for the specified number of iterations. The 95% CI is defined by the 2.5th and 97.5th percentiles of ΔJ*.
  7. Two-sided P value = 2 × min[P(ΔJ* ≤ 0), P(ΔJ* ≥ 0)].
ΔJ = J₁ − J₂. A difference in maximum Youden index is considered statistically significant when the 95% CI excludes 0 and P < 0.05.
Compares the AUCs of paired ROC curves.
Assumptions: ROC curves must be based on the same cases and the same binary outcome. Every case must have continuous or ordinal scores for both models. DeLong’s test compares overall AUC, not cutoff, sensitivity, specificity, or accuracy.
View the DeLong comparison method
The covariance between paired model scores is used to estimate the standard error of the AUC difference, followed by calculation of the Z statistic and two-sided P value. If a combined model is developed and evaluated in the same dataset, its apparent performance may be optimistic.
Compares classification accuracy in the same cases.
Assumptions: Both models must produce binary classifications for the same cases using the same reference outcome. Each model is classified using its own maximum-Youden cutoff; therefore, the McNemar result applies to those cutoffs.
View the McNemar comparison method
The test uses only discordant cases: Model 1 correct/Model 2 incorrect and Model 1 incorrect/Model 2 correct. The primary result is a two-sided exact McNemar test; a continuity-corrected P value is also reported.
Default: 5,000 iterations.
The same seed reproduces results under the same tool version and data order.

Paired Bootstrap: Youden Index Comparison

Youden Index Comparison Procedure

  1. Calculate the original maximum Youden index for each model using the same complete cases.
  2. Resample positive and negative cases separately with replacement; all models share the same resampled indices in each iteration.
  3. Fix the original ROC direction and re-optimize the cutoff and maximum Youden index in every resample.
  4. Calculate ΔJ* in each iteration, use percentile limits for the 95% CI, and test the two-sided null hypothesis of zero difference.
J = Sensitivity + Specificity − 1
ΔJ* = J₁* − J₂*
P = 2 × min[P(ΔJ* ≤ 0), P(ΔJ* ≥ 0)]

Interpretation requirements: The analysis compares the re-optimized maximum Youden index in each bootstrap sample, not the Youden index at a fixed cutoff. A random seed ensures reproducibility only under the same tool version and data order.

DeLong’s Test: AUC Comparison

Interpretation requirements: Models must be evaluated in the same complete cases with the same outcome. This test only evaluates whether AUCs differ; it does not determine which model has better accuracy, sensitivity, or specificity at a particular cutoff.

McNemar’s Test: Accuracy Comparison

Interpretation requirements: Both models must provide binary classifications for the same cases. Each model uses its own maximum-Youden cutoff. The primary result is the two-sided exact test, with the continuity-corrected P value reported as a supplement.
